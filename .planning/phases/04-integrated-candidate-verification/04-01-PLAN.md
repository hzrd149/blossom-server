## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Persisted blob metadata → browser response | Database MIME metadata controls whether untrusted stored bytes are rendered inline or forced to download. |
| Client conditional header → blob router | Untrusted If-None-Match syntax controls whether the route returns 304 before opening a blob stream. |
| Route policy → local storage stream | Shared headers and conditional decisions must remain independent of cosmetic suffixes and preserve zero-copy/range behavior. |
