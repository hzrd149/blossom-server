## Trust Boundaries

| Boundary                                                | Description                                                                                     |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Encoded request URL → decoded static candidacy          | Attacker-controlled encoding and length must be screened before Hono's Deno filesystem adapter. |
| URL filename segment → content-address metadata/storage | Only the exact accepted grammar may become a normalized SHA-256 lookup key.                     |
| Cosmetic requested suffix → response/storage metadata   | Untrusted suffix text must not control response MIME or physical storage extension.             |
