## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Authorization header → verified BUD-11 event | Attacker-controlled encoding, tags, timestamp text, and signature cross into trusted auth context. |
| Verified auth event → protected route/hash | A valid signer and verb must still be authorized for the exact blob affected by upload preflight/write or delete. |
| Rejected upload request/staged file → storage lifecycle | Authorization denial must release request/staging resources before worker, commit, metadata, or ownership mutation. |
| Upstream PR #62 → local release integration | Useful strictness must be adapted without importing an undocumented client-breaking lifetime policy or losing attribution. |
